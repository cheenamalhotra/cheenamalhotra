## 🚀 What I Build

I'm a **Software Engineer @ Microsoft** on the **Azure Data / SQL Server** team, focused on client-side database connectivity and developer tooling for the .NET ecosystem.

- 🔌 **[Microsoft.Data.SqlClient](https://github.com/dotnet/SqlClient)** — The official .NET data provider for SQL Server & Azure SQL. I work on the core driver: TDS protocol, security, performance, and cross-platform support.
- 🔐 **Azure AD / Entra ID Authentication** — Integrating MSAL-based auth flows (interactive, device-code, managed identity, workload identity) into SQL connectivity.
- 🗝️ **Always Encrypted & Azure Key Vault** — Column-level encryption for SQL Server data at rest and in transit.
- 🛠️ **SQL Developer Tooling** — Building tools like [`sqlconnectionstrings`](https://github.com/cheenamalhotra/sqlconnectionstrings) to simplify the SQL developer experience.
- ☁️ **Azure Integrations** — Azure Functions, WPF apps, and cloud-native patterns with SQL Server.
